# features

One row per feature vault under `dev/features/`, binding it to the project branch it is built on: ``- [ ] <slug> on `<branch>` - <what it delivers>``. `resume` and `plan` act on the open feature whose branch is checked out; `--feature <slug>` overrides, and a branch with no open row uses the project vault. One open row per branch. A closed feature keeps its row: `[x]` delivered, `[-]` naming where the work went (`SUPERSEDED BY`, `ABSORBED BY`, `WITHDRAWN`, `DEFERRED TO` or `SPLIT INTO`).
