## Ordered work

Milestones are `P<n>-M<k>`, allocated in order and never renumbered: position is order, the ID is identity. `[ ]` open, `[x]` closed as delivered, `[-]` closed without delivering - and every `[-]` names where the work went and the decision that moved it. A milestone gets a plan only where the detail would crowd this file; the plan is `dev/plans/p<n>-m<k>-<slug>.md`, linked from its row.
